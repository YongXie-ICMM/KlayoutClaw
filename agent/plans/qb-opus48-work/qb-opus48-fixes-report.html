4. 已实现的修复（10 项）

#2 — solidity 详情指标反转 tools/evaluate_worker.py

_prim_solidity 原返回裸 float；direction=below 时 score=(1−solidity)，再被通用格式化器标成 solidity: 0.60，让 raw solidity 0.40 的合格凹形 mesa 读起来像不合格。改为返回 dict，detail 同时给出 raw solidity 与归一化 score，并把 raw_solidity 提升到 check 结果。

detail: "solidity raw=0.4012 threshold=0.90 direction=below -> pass score=0.5988"
extra:  {"raw_solidity": 0.4012, "threshold": 0.9, "direction": "below", "passed": true}

#3 — auto_route 网格裁剪到 pin 子区域 + cell 数守卫 tools/route_worker.py

  • 路由窗口从「整个 cell.bbox() + margin」改为「全部 pin 区域并集 + 30% 对角 slack」，clamp 到 cell（只会变小，已 fit 的布局路由结果不变）。
  • 新增硬性 cell 数守卫（25M 上限）：超限自动粗化 map_resolution，避免 numpy 被 SIGKILL（exit -9/137）。
  • 新增可选 routing_bbox 参数；返回新增 routing_grid {rows,cols,cells,window_um}（可观测，便于 agent 与测试）。

#7 — 未知 arg 拒绝 + describe_checks + 扩展 layer_map 校验 plugin/klayoutclaw_server.lym

  • 新增 _allowed_args 表（已交叉验证为 worker 实际读取 args 的超集，不会误拒合法调用）；未知 arg key 现在抛可操作报错而非静默忽略。
  • 新增 describe_checks 模式：返回 {primitives, required_args, allowed_args, layer_ref_args}，schema 可自描述。
  • 把 layer_map 引用校验扩展到 materials/bulk_region/graphene/graphite/classes（typo 原本静默 0.0，现报错）。

#16 — planner CLI 模板对齐脚本 argparse agent/src/tools/klayout/nanodevice.ts

数据驱动测试（解析每个脚本 argparse 对比命令）揪出 10 处错误模板（远超 triage 列的 3 例）：image 作位置参数、footprint 缺 --source/--target/--bottom、transform 用了不存在的 --detect-dir、sweep/refine/top_hbn/ecc_register/overlay 缺多个 required flag。全部修正为与 argparse 一致。

8. 后续特性：auto_route 自适应两层路由（用户追加需求）

动机（用户指出 #3 的真实短板）：真实器件里 inner contacts 在中心、bonding pads 在最外围，pin_a ∪ pin_b ≈ 整个 layout，所以 #3 的"裁到 pin 子区域"对真实拓扑是 no-op，单遍网格只能统一粗化、糊掉密集的 inner contacts。正解是自适应两层（inner 细 / outer 粗）：像 route_multiwindow skill，但自动判定样品区域（两组 pin 里 bbox span 小的那组 = 样品）而非写死在中心。决策（用户选）：做进 auto_route MCP 工具（agent 默认就用它，杠杆最大）。

设计（route() 零改动，复用它跑两遍 — 低风险）

  • 新增 two_level 参数 auto(默认)/on/off。auto 仅在"清晰内外分离(≥3x) + 细分辨率铺满全场会超 25M cell(单遍本就 OOM) + ≥3 pin/组 + inner 窗细分辨率能 fit"时触发，否则单遍——对正常布局完全无副作用。
  • route_two_level orchestrator：检测内外→ordered_loop_match 配对(唯一一次,crossing-free)→每网算边界点(从内窗中心朝 pad 射线∩内窗边)→写临时边界 pin 层→route() pass1(inner,routing_bbox=内窗,细 res,pin_pairs_override)→内层路由写临时障碍层→route() pass2(outer,粗 res,障碍+内层层)→边界 patch→合并返回。
  • 边界 pin↔net 用坐标精确对账（不赌 shape 迭代顺序==插入顺序）；端点连续性由 route() 既有的"端点对齐 pin 中心"保证 inner[-1]==outer[0]，patch 兜底。
  • 纯几何/触发逻辑独立成 tools/two_level.py（仅 math，可单测）。
