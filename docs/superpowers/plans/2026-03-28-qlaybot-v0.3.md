# qlaybot v0.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade qlaybot's TUI to match qdevbot's polished Ink interface, and add context compaction.

**Approach:** Build from Ink primitives following qdevbot's architectural evolution. Reference `~/qdevbot` for design patterns and Ink usage, but implement independently for qlaybot's KLayout domain — no direct file copying, each component built understanding the why behind the design.

**Architecture:** Theme + markdown renderer as foundation. Input hooks for cursor/history/completion. Decomposed message components (UserMessage, AssistantMessage, SystemMessage) with ToolPanel and ThinkingIndicator. Compaction pipeline: pruner → stateLoader → autoRecall.

**Tech Stack:** TypeScript, Pi-Agent SDK, Ink 6, React 19, cli-highlight, marked, chalk, vitest

**Test Policy — MANDATORY, NO EXCEPTIONS:**
- `npm test` must run ALL tests after every task. Never use `QLAYBOT_E2E=0` or `--skip` flags during development.
- KLayout MCP must be running at :8765 for E2E tests. Verify with `curl -s http://127.0.0.1:8765/mcp` before claiming tests pass.
- If a test fails, FIX it. Do not skip, delete, comment out, or wrap in `.skip`. Do not change test expectations to match broken behavior.
- Report the FULL test output (`npm test -- --reporter=verbose`) — show test count, pass/fail/skip breakdown. If any tests are skipped, explain why.
- The final test count must be strictly greater than 82 (the v0.2 baseline). Any decrease means tests were lost.
- **5g exception:** Test 5g (long session resilience, 10+ turns) is gated behind `QLAYBOT_NIGHTLY=1` due to cost. It is the ONLY allowed skip during per-task test runs (Tasks 1-12). It MUST be written in Task 12 and MUST run and pass in Task 13 with `QLAYBOT_NIGHTLY=1 npm test`. Per-task checkpoints say "5g skipped until Task 13" — this is expected, not cheating.

**Spec:** `docs/superpowers/specs/2026-03-28-qlaybot-v0.3-design.md`

**Reference:** `~/qdevbot/src/tui/` for Ink patterns and design decisions

**Codebase entry points:** `agent/src/tui/` (TUI), `agent/src/agent.ts` (session), `agent/src/config.ts` (config)
