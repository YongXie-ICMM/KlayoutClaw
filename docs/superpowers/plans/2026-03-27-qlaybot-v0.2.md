# qlaybot v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add dual-mode commands, thinking toggle, planning mode, background tasks, global CLI, and agentic E2E tests to qlaybot.

**Architecture:** A `CommandRegistry` provides unified command handling for shell, TUI, and RPC. `PlanManager` wraps tools with a sandbox filter. `BackgroundTaskManager` runs allowlisted tools asynchronously. All new modules plug into the existing `QlayBotSession` interface.

**Tech Stack:** TypeScript, Pi-Agent SDK, Ink/React, vitest, better-sqlite3

**Spec:** `docs/superpowers/specs/2026-03-27-qlaybot-v0.2-design.md`

**Codebase entry points:** `agent/src/agent.ts` (session factory), `agent/src/cli.ts` (CLI), `agent/src/rpc.ts` (RPC server), `agent/src/tui/` (TUI)
